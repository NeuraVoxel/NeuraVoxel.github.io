# 乐乐工坊 Logo 使用说明

## 文件结构

```
logos/lele-workshop/
  icon/          full-color · mono-dark · mono-light
  horizontal/    full-color · mono-dark · mono-light
  vertical/      full-color · mono-dark · mono-light
  wordmark/      full-color · mono-dark · mono-light
  preview.html
  USAGE.md
```

## 色彩

| 角色 | 色值 |
|------|------|
| 陶赭 | `#C45C26` |
| 暖木 | `#8B5E3C` |
| 蜜金 | `#E8A838` |
| 单色深 | `#2C2416` |
| 单色浅 | `#FFF8F0` |

## 自媒体用法

| 场景 | 推荐文件 |
|------|----------|
| 抖音 / 小红书头像 | `icon/full-color.svg` |
| 浅色视频角标 | `icon/full-color.svg` 或 `icon/mono-dark.svg` |
| 深色视频角标 | `icon/mono-light.svg` |
| 片头 / 片尾横条 | `horizontal/full-color.svg` |
| 故事页居中封面 | `vertical/full-color.svg` |
| 字幕条纯文字 | `wordmark/*.svg` |

## 尺寸与留白

- 图标最小宽度 **32px**；横排最小 **120px**
- 头像四周留白约等于图标边长的 **10%**
- 勿拉伸变形；等比缩放

## 禁止

- 改色超出色板、加阴影/光晕、旋转歪斜
- 在杂乱背景上直接贴全彩版（先加半透明底或改用单色）

## 预览

本地打开 `preview.html` 查看全部变体。
