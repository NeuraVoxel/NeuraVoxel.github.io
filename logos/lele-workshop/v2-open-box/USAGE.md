# 乐乐工坊 Logo v2 · 开盒一瞬 使用说明

## 路径

`logos/lele-workshop/v2-open-box/`

旧稿锤印方案在 `../v1-hammers/`，概念草图在 `../concepts/`。

## 色板

| 角色 | 色值 |
|------|------|
| 陶赭（盒身） | `#C45C26` |
| 暖木（盒盖） | `#8B5E3C` |
| 腔体深木 | `#6B4530` |
| 蜜金（惊喜点） | `#E8A838` |
| 单色深 | `#2C2416` |
| 单色浅 | `#FFF8F0` |

## 自媒体用法

| 场景 | 文件 |
|------|------|
| 头像 | `icon/full-color.svg` |
| 浅色视频角标 | `icon/full-color.svg` / `mono-dark` |
| 深色视频角标 | `icon/mono-light.svg` |
| 片头片尾 | `horizontal/full-color.svg` |
| 封面居中 | `vertical/full-color.svg` |
| 字幕条 | `wordmark/*.svg` |

## 约定

- 图标 ≥ 32px；横排 ≥ 120px  
- 头像留白约 10%  
- 勿拉伸、改色、加阴影光晕  

本地预览：打开 `preview.html`。
