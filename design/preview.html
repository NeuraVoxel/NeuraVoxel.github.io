Data Management Platform

闭环以 DMP 为核

DMP 是驱动标注、训练/微调、仿真等模块的数据中枢——不是环上并列的一步，而是组织、版本、权限、分发与回流的中心。

Core

DMP

数据集组织 · 版本 · 权限 · 分发 · 回流

  1. 01 标注对接 任务下发与标注结果回流
  2. 02 训练 / 微调 版本化数据集拉取与产物登记
  3. 03 仿真验证 场景包分发与评估回流
  4. 04 数据回流 元数据写回，闭环再次启动

DMP 与其他平台的交互

  • 下载 版本化数据集、清单校验、批量下载
  • API HTTP 服务化接口：拉数与回写元数据
  • DDS 实时 / 近实时流式通道（车端 · 机器人 · 仿真）
