# 乐乐工坊独立 Logo 设计

**日期:** 2026-08-30  
**状态:** 已确认并交付 SVG 资产  
**范围:** 独立品牌标志（短视频 / 自媒体宣传），不改动官网页头  
**资产路径:** `logos/lele-workshop/`

## 1. 背景与目标

乐乐工坊是智樾云飞体系下的制造子品牌，口号「开物造环，匠心成器」。本 logo 用于抖音、小红书等平台宣传工坊产品，需与母品牌青绿闭环视觉**弱关联、独立气质**。

## 2. 决策摘要

| 项 | 选择 |
|----|------|
| 与母品牌关系 | B · 独立暖工坊气质 |
| 版式 | C · 图标 + 横排组合（含竖排、字标） |
| 概念方向 | 1 · 双乐锤印 |

## 3. 标志概念

**双乐锤印：** 两把几何化圆润小锤十字交叉；锤头内侧意趣贴近微笑 /「乐」；交叉中心蜜金点睛。不使用母品牌青绿环、飞飞元素。

## 4. 色彩

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 陶赭 | `#C45C26` | 锤头 / 主色图标 |
| 辅色 · 暖木 | `#8B5E3C` | 锤柄 / 字标深色 |
| 点缀 · 蜜金 | `#E8A838` | 中心点、微笑弧 |
| 单色深 | `#2C2416` | 浅底 |
| 单色浅 | `#FFF8F0` | 深色视频底反白 |

## 5. 版式与交付

- `icon/` — 1:1 头像、角标水印  
- `horizontal/` — 左标右字（可选英文副标）  
- `vertical/` — 上标下字  
- `wordmark/` — 仅「乐乐工坊」  

每种：`full-color` · `mono-dark` · `mono-light`  

路径：`logos/lele-workshop/`

## 6. 字标

- 中文：几何无衬线、略圆、中粗  
- 英文 `Lele Workshop`：细、字距略松；仅组合版，不进头像  
- SVG 字体栈：PingFang SC / Hiragino Sans GB / Noto Sans SC / Microsoft YaHei / sans-serif  

## 7. 使用约定

- 头像留白 ≥ 图标边长约 10%  
- 浅色视频底用陶赭/深色版；深色底用蜜金或反白  
- 最小宽：图标 ≥ 32px；横排 ≥ 120px  
- 禁止：拉伸、改色、加阴影光晕、旋转歪斜  

## 8. 非目标

- 不修改网站现有导航 / 页头 logo  
- 本期不批量导出 PNG
