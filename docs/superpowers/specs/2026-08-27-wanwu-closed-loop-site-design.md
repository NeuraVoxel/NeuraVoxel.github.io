# NeuraVoxel 官网改版设计：万物闭环

**日期：** 2026-08-27  
**状态：** 待审阅  
**域名：** `neuravoxel.cn`（暂不变更）  
**背景：** 在 NeuraVoxel 域名下，将站点叙事从「产品功能门户」升级为「万物闭环世界观 + 工具实践展示」，三层页面分别服务不同受众。

---

## 1. 目标与定位

### 1.1 一句话定位

> NeuraVoxel — 以万物闭环思维，用 Agent 一点点攻克每个环节。

### 1.2 品牌层级

```
万物闭环（世界观 / 方法论）
    │
    ├── 官网载体：NeuraVoxel.cn（暂时，域名不变）
    │
    └── 工具产品（现阶段统一展示，未来可拆品牌）
            ├── 自动驾驶系列（DMP、标注桥、训练桥、仿真桥…）
            ├── English-Agent（教育学习闭环）
            ├── Task-Agent（日常办公闭环）
            └── 未来：制造、教育…
```

### 1.3 品牌表达策略（渐进式）

| 位置 | 表达 |
|------|------|
| 页眉 | NeuraVoxel logo + 小字 tagline「万物闭环」 |
| 首页 Hero | 先讲闭环精神，再落到「我们正在做的事」 |
| 工具页 | 务实、功能导向，弱化哲学 |
| 文章页 | 哲学和方法论主场 |
| 页脚 | 版权仍用 NeuraVoxel，附一句万物闭环理念 |

### 1.4 受众分层

| 页面 | 受众 | 核心任务 |
|------|------|----------|
| 首页 `/` | A — 客户 / 合作伙伴 | 理解闭环价值，订阅关注 |
| 工具页 `/tools` | B — 开发者 / 技术同行 | 找到工具，直接使用 |
| 文章页 `/articles` | C — 思想认同者 / 行业读者 | 深入闭环思维，长期追随 |

### 1.5 非目标（本期）

- 用户登录、鉴权、站内真实任务操作
- 工具品牌拆分（English-Agent、Task-Agent 独立品牌页留待 Phase 3）
- 万物闭环独立域名
- 完整英文内容（框架预留，内容可先中文）

---

## 2. 方案选择

在三种路线中选定 **方案 A：哲学门户**：

- 站点仍以 NeuraVoxel 为域名，首页叙事升级为「万物闭环世界观」
- 工具页、文章页分别服务开发者和思想读者
- 域名不变，SEO 和现有链接不受影响
- 订阅 CTA 自然落在首页，文章页承接长期关注

**未选方案：**

- 方案 B（产品目录优先）：首页偏 B，弱化 A 受众，理念品牌难以立住
- 方案 C（沉浸式叙事站）：开发成本高，工具页和文章页难以独立迭代

## 4. 首页设计（受众 A）

**任务：** 30 秒内让访客理解「万物闭环」是什么、NeuraVoxel 在做什么、为什么值得关注。主 CTA 为订阅 / 关注。

### 4.1 第一屏 Hero

- **主标题：** 万物闭环（或「万物皆可闭环」）
- **副标题：** 从闭环视角分析问题、设计产品、驱动迭代
- **支撑句：** 在 AI 时代，我们用 Agent 智能体一点点攻克闭环中的每个环节
- **主 CTA：** 订阅更新（邮件 / 公众号二维码弹层）
- **次 CTA：** 探索工具 → `/tools`
- **视觉：** 中心闭环动画，环节依次点亮

### 4.2 第二屏：闭环思维是什么

三段式解释（面向非技术决策者）：

| 维度 | 内容 |
|------|------|
| 看问题 | 任何事物都是一个环：输入 → 处理 → 输出 → 反馈 → 再输入 |
| 做产品 | 不是做单点工具，而是识别环上断点，逐个连接、逐个闭环 |
| AI 时代 | Agent 让环上每个环节都可以智能化 |

配通用闭环图（不绑定具体行业）。

### 4.3 第三屏：我们在攻克的场景

场景卡片（2–3 个，可扩展）：场景名、一句话闭环描述、工具数量、链接到 `/tools#场景`。

首期场景：自动驾驶、教育学习、日常办公、更多场景（四个一级场景；更多场景为规划中占位）。

### 4.4 第四屏：距离终极闭环还很远

坦诚表达长期主义：

> 每个场景、每个应用，都需要从小做起。我们不做大而全的平台，而是做好每一个小工具，连接环上的每一个断点。终极闭环很远，但每攻克一个环节，环就更完整一分。

### 4.5 第五屏：订阅 CTA

- 标题：关注我们的闭环实践
- 说明：每周更新闭环思维、场景复盘、新工具发布
- 入口：邮件订阅、微信公众号

## 5. 工具页设计（受众 B）

**任务：** 快速找到需要的工具，知道它解决闭环哪一环，一键直达使用。

### 5.1 页面结构

- 页头：「NeuraVoxel 工具集 — 闭环中的每个环节，一个工具攻克一个断点」
- 场景 Tab 筛选：全部 / 自动驾驶 / 教育学习 / 日常办公 / 更多场景
- 工具卡片网格
- 页脚

### 5.2 工具卡片

每张卡片包含：

- 名称 + 状态（已上线 / 内测 / 规划中）
- 一句话描述
- 闭环环节标签（彩色小标签）
- 主按钮：打开工具（外链）
- 次按钮：查看文档（如有）

### 5.3 单工具页

Phase 1 可省略：English-Agent、Task-Agent 等轻量工具卡片 + 外链即可。复杂工具（如 DMP）后续可加 `/tools/[id]` 独立页。

## 7. 视觉风格

### 7.1 整体调性

| 维度 | 方向 |
|------|------|
| 气质 | 深邃、理性、有远见——「思考者的工具站」 |
| 色彩 | 深色底 + 高亮信号色（青 / 绿），闭环环节用信号色依次点亮 |
| 字体 | 中文无衬线 + 英文等宽（标签、代码） |
| 图形 | 闭环环图是核心视觉母题；避免仪表盘、数据大屏风格 |
| 动效 | 克制：环节依次点亮、数据沿环流动 |

### 7.2 各页面调性

| 页面 | 调性 |
|------|------|
| 首页 | 开阔、叙事感、有呼吸感 |
| 工具页 | 紧凑、功能导向、信息密度高 |
| 文章页 | 阅读友好、留白多、优质博客感 |

### 7.3 闭环环节标签色（全站复用）

| 环节 | 色 |
|------|-----|
| 感知 / 采集 | 蓝 |
| 标注 / 处理 | 紫 |
| 训练 / 优化 | 橙 |
| 仿真 / 验证 | 黄 |
| 回流 / 迭代 | 青（主信号色） |

## 8. 分期上线

### Phase 1 — MVP（2–3 周）

- 首页改版：Hero + 闭环思维 + 场景卡片 + 订阅 CTA
- 工具页：场景分类 + 工具卡片（含现有工具数据）
- 文章页：列表框架 + 1–2 篇种子文章
- 导航 / 页脚 / 关于页更新
- 中英文框架预留（内容可先中文）

### Phase 2 — 内容填充（持续）

- 补齐 3–5 篇种子文章
- 各工具补文档链接
- 订阅功能接入（邮件服务 / 公众号）

### Phase 3 — 品牌演进（远期）

- 工具品牌拆分（English-Agent、Task-Agent 独立品牌页）
- 域名策略评估（是否新增万物闭环独立域名）
- 闭环动画交互增强
