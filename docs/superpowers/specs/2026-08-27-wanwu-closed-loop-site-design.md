## 1. 目标与定位

### 1.1 一句话定位

> 智樾云飞 — 以万物闭环思维，用 Agent 一点点攻克每个环节。

### 1.2 品牌层级

```
万物闭环（世界观 / 方法论）
    │
    ├── 主品牌：智樾云飞 / ZeyoFly（zeyofly.com）
    │
    ├── 工坊品牌：乐乐工坊（产品制造与展示）
    │
    ├── 智能助手：飞飞助手（全站右下角卡通小鸟）
    │
    └── 产品（按场景归类，现阶段统一展示）
            ├── 自动驾驶：NeuraVoxel 系列（DMP、标注桥、训练桥、仿真桥…）
            ├── 教育学习：English Agent
            ├── 日常办公：Task Agent
            └── 未来：制造、医疗…
```

### 1.3 品牌表达策略

| 位置 | 表达 |
|------|------|
| 页眉 | 智樾云飞 logo + ZeyoFly + tagline「万物闭环」 |
| 首页 Hero | 先讲闭环精神，再落到「我们正在做的事」 |

| 页脚 | 版权智樾云飞 ZeyoFly；多栏链接 + 唯一公众号二维码 |

| 页面 | 受众 | 核心任务 |

## 4. 首页设计（受众 A）

**任务：** 30 秒内让访客理解「万物闭环」是什么、智樾云飞在做什么、为什么值得合作。主 CTA 为合作咨询。

### 4.1 第一屏 Hero

- **主标题：** 万物闭环
- **副标题：** 从闭环视角分析问题、设计产品、驱动迭代
- **支撑句：** 智樾云飞以 Agent 智能体一点点攻克闭环中的每个环节——从小工具做起，连接每一个断点
- **主 CTA：** 合作咨询 → `/contact`
- **次 CTA：** 探索工坊 → `/workshop`
- **视觉：** 中心闭环动画，环节依次点亮

### 4.2 第二屏：闭环思维是什么

三段式解释（面向非技术决策者）：

| 维度 | 内容 |
|------|------|
| 看问题 | 任何事物都是一个环：输入 → 处理 → 输出 → 反馈 → 再输入 |
| 做产品 | 不是做单点工具，而是识别环上断点，逐个连接、逐个闭环 |
| AI 时代 | Agent 让环上每个环节都可以智能化 |

配通用闭环图（不绑定具体行业）。

### 4.3 第三屏：我们在攻克的场景

场景卡片（四个一级场景）：场景名、一句话闭环描述、链接到 `/workshop#场景`。

首期场景：自动驾驶、教育学习、日常办公、更多场景（规划中占位）。

### 4.4 第四屏：距离终极闭环还很远

坦诚表达长期主义：

> 每个场景、每个应用，都需要从小做起。我们不做大而全的平台，而是做好每一个小工具，连接环上的每一个断点。终极闭环很远，但每攻克一个环节，环就更完整一分。

### 4.5 第五屏：合作 CTA（垂直布局）

- **布局：** 垂直居中——标题、说明、按钮上下排列，整体居中（`subscribe-strip` 组件）
- **标题：** 与智樾云飞合作
- **说明：** 产品共建 · 场景对接 · 技术合作 — 从一个小环节开始，一起把环做完整
- **按钮：** 合作咨询 → `/contact`

> **变更说明：** 原「邮件订阅 + 微信公众号」双入口已移除；公众号仅在页脚保留一处。

## 5. 乐乐工坊设计（受众 B）

**任务：** 快速找到需要的产品，知道它解决闭环哪一环，一键直达使用。

### 5.1 页面结构

- 页头：乐乐工坊 — 快快乐乐生产制造
- 工坊介绍：乐 / 匠 / 坊 四卡片（2×2 网格），强调工匠精神
- 场景 Tab 筛选：全部 / 自动驾驶 / 教育学习 / 日常办公 / 更多场景
- 产品卡片网格
- 页脚

### 5.2 产品卡片

每张卡片包含：

- 名称 + 状态（已上线 / 内测 / 规划中）
- 一句话描述
- 闭环环节标签（彩色小标签）
- 主按钮：打开产品（外链）
- 次按钮：查看文档（如有）

### 5.3 单产品页

Phase 1 可省略：English Agent、Task Agent 等轻量产品卡片 + 外链即可。复杂产品（如 DMP）后续可加独立页。

## 9. 视觉风格

### 9.1 整体调性

| 维度 | 方向 |
|------|------|
| 气质 | 深邃、理性、有远见——「思考者的工具站」 |
| 色彩 | 深色底 `#080c12` + 信号色 `#40b8b0`（青），闭环环节依次点亮 |
| 字体 | Noto Serif SC 标题 + Figtree 正文 + IBM Plex Mono 标签 |
| 图形 | 闭环环图是核心视觉母题；避免仪表盘、数据大屏风格 |
| 动效 | 克制：环节依次点亮、数据沿环流动 |

### 9.2 各页面调性

| 页面 | 调性 |
|------|------|
| 首页 | 开阔、叙事感、有呼吸感 |
| 工坊页 | 紧凑、功能导向、信息密度高 |
| 文章页 | 阅读友好、留白多、优质博客感 |
| 合作咨询 | 表单清晰、信息分组、专业可信 |

### 9.3 闭环环节标签色（全站复用）

| 环节 | 色 |
|------|-----|
| 感知 / 采集 | 蓝 |
| 标注 / 处理 | 紫 |
| 训练 / 优化 | 橙 |
